# Security

## Supported versions

Only the latest commit on the default branch is supported. Older builds are not patched.

## Reporting a vulnerability

Please do **not** open a public issue for a security problem.

Report it privately with GitHub Security Advisories on this repository, or email the address on the latest git commits. Include enough detail to reproduce the problem.

You can expect an acknowledgement when the report is seen, and an update when there is a fix or a decision not to change the code.

## Scope

In scope: the Drake tray app, the overlay plugin, the installer, and the way settings and the check in token are stored.

Out of scope: the League of Legends client itself, and third party loaders you may already have installed.
